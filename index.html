Projects

Monte Carlo pricing of a European call

A Python notebook that prices a call option by simulation and compares four estimators on the same budget of 1,000 simulated payoffs: standard Monte Carlo, antithetic variates, a control variate, and the last two combined. Every estimate has a 95% confidence interval, and the exact Black–Scholes price is the reference.

Combined, the variance is about 21 times smaller than with standard Monte Carlo (the typical error is about 4.6 times smaller). The error of every method shrinks like N−1/2, and the confidence intervals contain the true price close to 95% of the time.

Built with
Python, NumPy, SciPy, pandas, Matplotlib
Checked by
Comparison with the exact price, 5,000 repeated experiments, and the measured convergence rate

Notebook and code on GitHub

Limit order book and matching engine

A Java simulator of how an exchange matches buy and sell limit orders for one instrument. It follows price-time priority, handles partial fills and cancellations, and rejects invalid orders.

It comes with 25 automated checks. One of them submits 5,000 random orders and verifies after each one that the book is never crossed, that orders stay in price-time order, and that no quantity is created or lost.

Built with
Java, no external libraries
Known limit
Inserting an order takes time proportional to the size of the book. Keeping one queue per price level in a sorted structure would be the next step.

How I work

I compare with a known answer. When an exact result exists, as with Black–Scholes, I check the simulation against it.

I report the uncertainty. An estimate without an error bar is not finished.

I test the rules, not only examples. Random tests check, after every step, properties that must always hold.

I use AI tools and make sure I understand the result. I use Claude to review and extend my code, and I only publish what I can explain line by line.
